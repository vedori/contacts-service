# CS 320
## How can I ensure that my code, program, or software is functional and secure?
I can use tooling and development patterns that shield against bias and highlight posible vulnerabilities in my code.
For example, writting test cases that reflect the requirements for a class beforehand ensures that the solution written matches the specifications.
Also, static testing tools such as dependency checking ensures that any third-party dependency used is up to date and shows possible vulnerabilities it may have.
Functional code comes from being consistent and breaking down the code into logical components that are not too verbose.
## How do I interpret user needs and incorporate them into a program?
User needs can be found through requirements gathering and user input given early in the development process.
Once user needs are identified, the system can be designed into components that match those requirements.
These requirements can be the basis of test cases for enabling test-driven development in the development of a program
## How do I approach designing software?
Software should be designed with the needs of the users in mind.
Design should also be structured in a way that makes it easy to implement the interactions the user would have with it.
Software afterall is made for users and the design for an application should reflect that.
